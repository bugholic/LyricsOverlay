Features

Stays out of your way

🖱️

Click-through

The strip sits on top of everything but clicks pass right through it. Work, game or browse as usual.

🎵

Detects the song

Reads what's playing from Windows media sessions, the same info the volume flyout shows. No setup.

📜

Player lyrics first

A small extension reads YouTube Music's own Lyrics tab, so you get the lyrics the player shows.

⏱️

Time-synced option

Allow LRCLIB for exact line timing. Free, no account, and off until you turn it on.

↔️

Move & resize

Tray → Move / resize overlay. Drag it anywhere, resize it, change text size with A− / A+.

🔒

Private by default

Everything runs locally. If you enable LRCLIB, only title, artist, album and length are sent.

Get started

Up and running in a minute

Run the app

Download and launch LyricsOverlay.exe. Settings opens on first run; after that it lives in the tray (♪).

Add the extension

Open chrome://extensions, turn on Developer mode, click Load unpacked and pick the extension folder.

Press play

Play a song on YouTube Music. Settings shows “✔ Browser extension connected” and the lyrics appear.
